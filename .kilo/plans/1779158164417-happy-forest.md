# 迁移 vscode-notes 侧边栏功能到 src

## 目标
将 `reference_repo/vscode-notes` 的侧边栏笔记功能迁移到 `src` 目录。

## vscode-notes 功能概览
- **TreeView 侧边栏**：在 VSCode 侧边栏显示笔记文件列表
- **笔记管理**：创建/删除/重命名笔记文件和文件夹
- **配置项**：`notes.notesLocation`、`notes.notesExtensions`、`notes.notesDefaultNoteExtension`

## 迁移计划

### 1. 创建 `src/notes/` 目录结构
```
src/notes/
├── note.ts              # Note 类，继承 TreeItem
├── notesViewProvider.ts # TreeDataProvider，实现侧边栏视图
└── notesCommands.ts     # 笔记相关命令（从 extension.ts 的 Notes 类提取）
```

### 2. 迁移文件

#### 2.1 `note.ts`
- 从 `reference_repo/vscode-notes/src/note.ts` 迁移
- 适配：使用中文注释，符合项目规范

#### 2.2 `notesViewProvider.ts`
- 从 `reference_repo/vscode-notes/src/notesViewProvider.ts` 迁移
- 适配：中文注释，符合项目规范

#### 2.3 `notesCommands.ts`（新增）
- 从 `extension.ts` 的 `Notes` 类提取
- 包含所有笔记操作命令：`deleteNote`、`deleteFolder`、`listNotes`、`newNote`、`newFolder`、`openNote`、`refreshNotes`、`renameNote`、`renameFolder`、`setupNotes`

### 3. 修改 `src/extension.ts`
- 导入并注册 `NotesViewProvider`
- 注册所有笔记命令
- 监听配置变化（检查 `smartPageTranslator.notes.notesLocation`）

### 4. 修改 `package.json`
#### 4.1 添加配置项
```json
"configuration": {
  "properties": {
    "smartPageTranslator.notes.notesLocation": {...},
    "smartPageTranslator.notes.notesExtensions": {...},
    "smartPageTranslator.notes.notesDefaultNoteExtension": {...}
  }
}
```

#### 4.2 添加 views（侧边栏）
```json
"views": {
  "explorer": [
    {
      "id": "notes",
      "name": "Notes"
    }
  ]
}
```

#### 4.3 添加 viewsContainer
```json
"viewsContainer": {
  "explorer": "notes"
}
```

#### 4.4 添加命令
- `Notes.deleteNote`、`Notes.deleteFolder`、`Notes.listNotes`、`Notes.newNote`、`Notes.newFolder`、`Notes.openNote`、`Notes.refreshNotes`、`Notes.renameNote`、`Notes.renameFolder`、`Notes.setupNotes`

#### 4.5 添加 menu（右键菜单）
- `explorer/context` - 文件夹右键菜单
- `editor/context` - 编辑器右键菜单

#### 4.6 添加 activationEvents
- `onView:notes`

### 5. 依赖更新
- 添加 `glob` 包（用于文件匹配，原项目使用）
- 检查 `rimraf` 是否需要（用于递归删除文件夹）

## 用户确认
- **功能范围**：全部迁移（包括笔记、文件夹的创建/删除/重命名等全部功能）
- **配置前缀**：`smartPageTranslator.notes.*`（如 `smartPageTranslator.notes.notesLocation`）

1. 创建 `src/notes/` 目录和文件
2. 修改 `package.json` 添加配置、views、commands、menus
3. 修改 `src/extension.ts` 集成功能
4. 更新依赖（如果需要）
